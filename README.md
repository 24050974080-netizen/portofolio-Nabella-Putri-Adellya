# portofolio-Nabella-Putri-Adellya
Website portofolio sederhana yang dibuat menggunakan HTML, CSS, dan Bootstrap. Website ini berisi beberapa halaman seperti home, about, gallery, contact, dan login. Pada halaman utama terdapat jumbotron dan carousel sebagai tampilan awal. Project ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Web.
